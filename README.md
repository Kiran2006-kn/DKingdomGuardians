# NEON BASTION // Tactical Cyber Defense

A feature-rich, browser-based Tower Defense game built with modern HTML5 Canvas, Tailwind CSS, and pure JavaScript, featuring a procedural Web Audio API synthesizer and tactical grid-based mechanics.

## 🚀 Features
* **Tactical Tower Arsenal:** Build and upgrade Pulse Lasers, Plasma Mortars, and specialized defense nodes with multi-tier upgrades.
* **Procedural Audio Engine:** Fully synthesized sound effects generated dynamically using the Web Audio API (zero external audio assets required).
* **AI Targeting Protocols:** Configure individual turrets with custom targeting rules (First, Strongest, Weakest, Closest).
* **Commander Abilities:** Trigger global Plasma Strikes and Turret Overclocks during intense wave rushes.

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS, Canvas API
* **Logic:** Pure JavaScript (OOP Architecture)
* **Audio:** Web Audio API
